# 🙈 숨바꼭질 온라인

브라우저로 친구들과 실시간으로 하는 멀티 숨바꼭질 게임입니다. (PC·모바일 모두 지원)

## 실행 방법

```bash
cd hide-and-seek
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 → **방 만들기** → **🔗 초대 링크 복사**로 친구에게 공유.
같은 와이파이의 친구는 `http://<내 PC IP>:3000` 으로 들어오면 됩니다.
혼자라면 대기실에서 **🤖 봇 추가** 후 시작하세요.

## 게임 규칙
- 술래 1명은 숨는 시간 동안 눈을 감고 움직일 수 없습니다. 나머지는 숨으세요.
- 벽·상자 너머는 보이지 않습니다(시야 안개). 🌳 덤불 안에 숨으면 술래가 바로 옆까지 와야 보입니다.
- 술래가 닿으면 잡혀서 유령(관전자)이 됩니다.
- 남은 60·40·20초에 숨은 사람의 대략적인 위치가 술래에게 노출됩니다.
- 술래가 가까워지면 화면 가장자리가 빨갛게 두근거립니다.
- 점수: 잡기 +2, 전원 검거 보너스 +3, 끝까지 생존 +3
- 라운드가 끝나면 술래를 돌아가며 자동으로 다음 라운드가 시작됩니다.

조작: WASD/방향키, 모바일은 화면 드래그(가상 조이스틱). Enter 채팅, Tab 점수판.

## 안정성 (밤새 돌려도 괜찮도록)
- 서버 권위형: 이동 속도·벽 통과 검증, 잡기 판정은 서버에서
- 시야 밖 플레이어 정보는 아예 전송하지 않음(치트 방지)
- 끊겨도 60초 안에 새로고침/재접속하면 같은 자리로 복귀, 방장 자동 위임
- 하트비트로 죽은 연결 정리, 빈 방 자동 삭제, 메시지 크기·빈도 제한
- 방 하나에서 오류가 나도 다른 방/서버에 영향 없음
- `/health` 에서 상태 확인 (가동 시간, 방/플레이어 수, 메모리)

안정성 테스트: `npm test` (기본 60초, `node test/soak.js 600` 처럼 시간 지정 가능)

## 설정 (환경 변수)
`PORT`(기본 3000), `HIDE_TIME`, `SEEK_TIME`, `END_TIME`(초)

## 인터넷에 올리기
Node.js를 지원하는 곳(Render, Railway, Fly.io 등)에 이 폴더를 올리고 시작 명령을 `npm start`로 지정하면 됩니다. WebSocket을 쓰므로 HTTPS 환경에서도 자동으로 `wss://`로 연결됩니다.
